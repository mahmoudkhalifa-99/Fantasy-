# فانتازي الدورات الشعبية

## الإعداد (Firebase بس)
التخزين والدخول كله على Firebase: **Authentication** للحسابات و**Firestore** للبيانات. مفيش Redis ولا ملفات محلية.

1. Firebase Console ← **Authentication ← Sign-in method ← Email/Password** فعّله (التسجيل الجديد يفضل شغال).
2. **Firestore Database ← Create database** (Production mode).
3. **Project settings ← Service accounts ← Generate new private key** وهينزل ملف JSON.
4. Vercel ← **Settings ← Environment Variables**: ضيف `FIREBASE_SERVICE_ACCOUNT` وحط فيه محتوى ملف الـ JSON كله، وبعدها **Redeploy**.
5. انسخ قواعد مجلد `firebase/` في Firebase Console (أو `firebase deploy --only firestore,database,storage` من داخله).
6. **اعمل حساب المنظم أول حاجة** (قبل ما أي حد يسجّل) بأي طريقة من دول:
   - Console ← Authentication ← Users ← **Add user** بإيميل `khalifa@fantasy.com` والباسورد.
   - أو بالسكريبت: `FIREBASE_SERVICE_ACCOUNT="$(cat serviceAccount.json)" ADMIN_PASSWORD="الباسورد" node scripts/create-admin.mjs`

## تشغيل محلي
ضيف `FIREBASE_SERVICE_ACCOUNT` في ملف `.env` ثم:
```bash
npm install
npm run dev   # http://localhost:3000
```

## المنظم والمشتركين
- **المنظم الوحيد: `khalifa@fantasy.com`** (ثابت في الكود، مفيش متغير بيضيف منظمين). بيدخل من `/admin`. هو بس اللي يقدر يضيف ويعدّل الفرق واللاعبين والمباريات والنتائج والإعدادات ويمسح البيانات.
- **أي حد يقدر يعمل حساب جديد** (إيميل + باسورد 6 حروف أو أرقام على الأقل + الاسم ورقم الموبايل) ويلعب. إيميل المنظم محجوز ومش بيتسجّل كمشترك من الموقع.
- المشترك يحفظ تشكيلته هو بس (باسم حسابه)، والسيرفر بيتحقق من الميزانية والخطة والحد من الفريق والتحويلات.
- أرقام الموبايل بتظهر للمنظم بس.

## وضع الحجز (الفايز باقي)
- من لوحة المنظم ← تبويب **🔁 الحجز**: اختار 3 أو 4 فرق وحدد مين يبدأ، وبعدها ابدأ.
- المباريات بتتسجل من **المباراة المباشرة** زي أي مباراة. لما تنهيها: الفايز بيفضل، المهزوم بيروح آخر الدور، والفريق اللي مستني بره بيدخل، والمباراة الجاية بتتعمل تلقائيًا.
- التعادل: بتختار مين يكمّل وقت الإنهاء، ولو ماختارتش الفريق الأقدم في الملعب بيخرج.
- الإجماليات لكل فريق (لعب/فاز/تعادل/خسر/له/عليه/فرق/نقاط/انتصارات متتالية) بتظهر للمشتركين في تبويب «الحجز» داخل شاشة المباريات.
- الحراس مستثنيين من الحد الأقصى للاعبين من الفريق الواحد.

## الإعلانات
من لوحة المنظم ← تبويب **📢 الإعلانات**: ضيف وعدّل وأوقف ومسح إعلانات الدواير اللي فوق في شاشة المباريات (تفاصيل أو رابط أو واتساب أو شاشة داخل التطبيق)، وحط رقم واتساب لزرار «أعلن معانا».

## قواعد Firebase
- **Firestore / Realtime Database / Storage**: مقفولة بالكامل للمتصفح (`firebase/*.rules`). السيرفر بس بيكتب ويقرأ بحساب الخدمة، فكل القواعد أعلاه بيطبقها السيرفر. لو فتحت القواعد للعميل أي مشترك يقدر يغيّر بياناته وتشكيلته بدون تحقق.
- **Authentication**: ملوش Rules. الحماية من إعدادات Sign-in method، وإيميل المنظم متحجوز بإنك تنشئه الأول.
- المستندات: `tournament/main` (الدورة) و`entries/{uid}` (تشكيلة كل مشترك).
- الحصة المجانية (Spark): 50 ألف قراءة و20 ألف كتابة في اليوم، ولو المشتركين كتير الأفضل Blaze.

## الملفات
`src/` الواجهة · `api/tournament/` الـ API على Vercel · `server.ts` سيرفر التطوير المحلي · `server/logic.ts` الصلاحيات والتحقق · `server/firestoreStorage.ts` التخزين · `scripts/create-admin.mjs` إنشاء حساب المنظم

## التسجيل المباشر للمباراة
لوحة المنظم ← تبويب **🔴 مباراة مباشرة**: اختار المباراة وادوس "ابدأ"، بعدين اختار الحدث (هدف/صناعة/كارت/...) وادوس على اللاعب.
النتيجة والهدافين وإحصائيات اللاعبين (نقاط الفانتازي) بتتحدّث لحظيًا، والمشتركين بيشوفوها تلقائيًا كل ~8 ثواني. فيه زر "تراجع" لآخر حدث.

## بيانات اللاعب (زي الفانتازي)
في سوق اللاعبين وشاشة التبديل: اسحب اللاعب لليمين (أو دوس 📊) فتظهر شاشة بيانات اللاعب: الماتش الجاي، إجمالي النقاط، نقاط/ماتش، الفورمة، لعب كام ماتش، الأهداف والصناعات والكروت، نسبة اختياره، وجدول كل جولة (الخصم والنتيجة والنقاط). كله محسوب من إحصائيات الجولات الفعلية.

## التحويلات والكروت
- **تحويل مجاني واحد كل جولة** (الإعداد من لوحة المنظم ← الإعدادات). كل تحويل زيادة بيتخصم **4 نقاط** (قابل للتغيير). أول تشكيلة لأي مشترك من غير حدود.
- التحويلات بتتحسب على السيرفر بمقارنة التشكيلة بتشكيلة الجولة اللي قبلها، فمفيش تلاعب من الجهاز.
- **Wildcard**: تحويلات من غير خصم في جولة، مرة واحدة في الدورة. **Free Hit**: تحويلات حرة لجولة واحدة وبترجع التشكيلة القديمة بعدها، مرة واحدة.
- الخصم بيتحسب في نقاط الجولة في الترتيب والإحصائيات.

## الحساب التلقائي من المباريات
المباريات هي مصدر الحقيقة. كل ما تحفظ أو تسجّل مباراة السيرفر بيحسب تلقائي:
- **إحصائيات اللاعبين:** الأهداف والصناعات والكروت والهدف العكسي والجزاءات ورجل الماتش والكلين شيت والمشاركة (من أحداث المباراة المباشرة، أو من قائمة الهدافين المكتوبة بالأسماء).
- **نقاط الفانتازي** لكل مشترك وكل جولة (مع خصم التحويلات)، و**الترتيب العام**، و**جدول الفرق** (لعب/فوز/تعادل/خسارة/له/عليه/نقاط)، و**الهدافين**.
- الماتش اللي خلص ومحددتش فيه مين لعب: كل لاعبين الفريقين بيتحسبوا مشاركين (وبيتحسب كلين شيت للي ما اتدخلش عليه).
- علامة الهدف العكسي في القائمة المكتوبة لازم تبقى بين أقواس: `اسم اللاعب (ع.م)`.

## مسح البيانات التجريبية
- النسخة دي بتبدأ **فاضية**: من غير فرق ولا لاعبين ولا مباريات ولا إحصائيات ولا مشتركين تجريبيين.
- لو الموقع عندك فيه بيانات تجريبية متخزنة من قبل: لوحة المنظم ← **الإعدادات** ← **🗑 مسح كل البيانات التجريبية**. بيمسح الفرق واللاعبين والمباريات والإحصائيات وتشكيلات المشتركين، وبيرجّع الجولة 1. **الحسابات (الاسم والموبايل) بتفضل**.
- بعد المسح ضيف فرقك ولاعبينك ومبارياتك من اللوحة.

## ترتيب المشتركين
كل مشترك يقدر يشوف ترتيبه ونقاطه وسط باقي اللاعبين من مكانين: زر **🏆 ترتيب المشتركين** في شاشة فانتازي، وتبويب **المشتركين** في شاشة الترتيب والجدول. بيعرض المركز وحركة الصعود/النزول عن الجولة اللي فاتت ونقاط الجولة والمجموع، وبطاقة بترتيبك والفرق بينك وبين المتصدر. النقاط بتتحسب تلقائي من المباريات.
